sworm GitHub ↗
open-source · MIT · self-hosted

When someone leaves,
their access ends.

Including the copy on their laptop. sworm is a self-hosted program: enroll machines, browse their files, run commands, and wipe scoped folders when an engagement ends.

list the fleet, browse a disk, run a command, offboard. one CLI.

▦ Fleet overview

Every enrolled machine with hostname, os, user, uptime, and last seen. swormctl list

▤ Browse any disk

Directory listings with sizes, depth capped, straight from the machine. swormctl tree

⇅ Pull and push files

Fetch files back or write small files out, with hard caps. pull · push

⌘ Remote shell

Run any command in a login shell, or open an interactive session. exec · shell

◈ Hardware info

cpu, ram, os, user, and timezone, collected once at enroll.

⏻ One-command offboarding

Scoped wipe of the folders you name, then the agent removes itself. swormctl wipe

Works with any project

Enrollment is per machine, not per project. One agent covers everything on that laptop.

npm package

For JS and TS repos. The postinstall enrolls on npm install and skips CI with a printed note.

"dependencies": {
  "sworm-agent": "file:./vendor/sworm-agent"
}

curl one-liner

For any other repo, any language. Run once after clone. The script is short and prints every step.

curl -s https://YOUR_WORKER_URL/install | bash

bundled installer

For shared folders and zips with no repo. Drop the filled-in install.sh in the folder with a note to run it once.

sh install.sh
